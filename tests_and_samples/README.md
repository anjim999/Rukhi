# Tests and Samples Directory

This folder contains all test scripts, sample videos, character concept anchors, and intermediate clips generated during pipeline testing.

## Directory Structure:
- `scripts/`: All standalone test and generation scripts (Veo 3.1, Gemini Vertex AI, Deepgram, TTS, and video rendering).
- `sample_outputs/`: Master generated sample films (e.g. `proposal_movie_scene_60s.mp4`, `veo_proposal_movie_full.mp4`, etc.).
- `intermediate_clips/`: Individual shot cuts, dialogue stems, and scene beat image frames.
